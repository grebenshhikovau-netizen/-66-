Векторный вариант карты с подписями морей и океанов по дугам.
Пробная компоновка для просмотра и дальнейшей правки.

- [SVG с текстом в кривых](макет/подложка-вариант-1-кривые.svg) — для переноса в CorelDRAW без зависимости от шрифтов.
- [Векторный PDF](макет/подложка-вариант-1.pdf)
- [Предпросмотр PNG](макет/предпросмотр.png)
