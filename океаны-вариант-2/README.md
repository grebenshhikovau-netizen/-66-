# Вариант 2 — только океаны

Это отдельный векторный слой названий океанов для исходного CDR, а не готовый объединённый макет. Подписи морей в этот слой не включены: их следует сохранить из исходного файла пользователя. Вариант 1 не использовать как окончательный.

- `океаны-вариант-2.svg`: текст по кривым, редактируемый.
- `океаны-вариант-2-кривые.svg`: буквы переведены в контуры для переноса в CorelDRAW.
- `океаны-вариант-2-проверка.png`: проверка океанов на контурах карты; моря намеренно не показаны. Это технический предпросмотр, не готовый макет.

Масштаб SVG соответствует исходному CDR: 72 единицы на дюйм. Полотно расширено, чтобы включить объекты за пределами исходной страницы. При импорте без масштабирования точка исходной страницы (0,0) находится на 342.194444 мм правее и 45.861111 мм ниже верхнего левого угла SVG. Импортировать на отдельный слой, совместить с исходной страницей, затем удалить только прежние подписи океанов из CDR. Импорт в самом CorelDRAW здесь не проверен.
