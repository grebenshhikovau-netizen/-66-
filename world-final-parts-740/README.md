# Острова, Гренландия, Австралия и общая сборка мира

Три самостоятельных новых комплекта, каждый на одном листе **740 × 740 мм**, по одному экземпляру, без поворотов, отражений или изменения размеров при раскладке. Четвёртый файл — общий мир в Blender.

Чёрный — сквозной рез. Красный — гравировка границ, городов, регионов и островов. Синий — названия стран. В SVG надписи остаются текстом: установить **Open Sans Light** из папки `Шрифт`. Контуры резки замкнуты; внутренние линии гравировки могут быть открытыми.

У Австралии основные восемь штатов и территорий отмечены гравировкой на видимых поверхностях; мелкая ACT обозначена Канберрой. Тасмания включена сюда. Рельеф стилизован по ETOPO10: широкое западное плато и восточные горные массивы, без лишних мелких возвышенностей.

У Гренландии три цельные ступени ледникового купола и шесть отдельных прибрежных островных деталей. Купол — художественная поверхность льда, не высоты подледного ложа. Добавлены города и четыре географических района; устаревшие муниципальные границы не нанесены.

Островной комплект дополняет актуальные материковые модели: Канадский архипелаг, Карибы, Новая Зеландия, восточная часть Новой Гвинеи и другие недостающие крупные острова исходника. Япония, Индонезия, Мадагаскар и острова, уже присутствующие в готовых материковых комплектах, не продублированы. Мелочь менее 18 мм² в координатах исходного атласа (~15,3 мм² в производственном масштабе) исключена; береговая рябь сглажена. Подписи добавлены там, где помещаются на одном открытом слое своего острова. Все острова сохраняют естественную раздельность, без искусственных перемычек между ними.

В новых Blender-файлах начала координат деталей находятся на нижней плоскости. Верхние слои и гравировка следуют изменению толщины нижнего. Файлы повторно открыты и проверены для основания 3 / 6 / 9 мм; все физические детали — отдельные связные замкнутые тела.

## Общая сборка

Включены четыре актуальные утверждённые сборки и три новых комплекта, **265 деревянных деталей**. Каждый исходник подключён один раз. Модели Северной и Южной Америки, России/Азии, Африки/Европы/Ближнего Востока сохранены с текущими вырезами и рельефом. У каждого блока свой управляющий Empty; Скандинавия остаётся самостоятельным вложенным блоком.

Для общего географического вида XY размещение приближённо согласовано с исходной проекцией атласа. Новые комплекты сделаны в производственном масштабе готовых России/Азии и Африки/Европы. Высоты по Z не масштабировались. Для производства использовать отдельные SVG; общий мир — файл расстановки. **Антарктида — исходный плоский ориентир без нового рельефа.**

## Проверки и воспроизведение

Результаты: `Проверка-раскроя.json`, `Проверка-нативных-файлов.json`, `Проверка-общей-сборки.json`. Минимальный проверенный зазор деталей: 4,67 / 5,15 / 4,87 мм. Нет самопересечений, повторных контуров резки или растровых объектов в SVG; все 77 надписей — обычный текст. Политические линии не проходят через надписи и не дублируют береговой рез.

Инструменты — `tools/`: Python + Shapely 2.2, NumPy, SciPy, Matplotlib, fontTools, lxml, Pillow; Blender 4.3+ (для него Shapely установлен под версию Python Blender). `prepare_world.py` регистрирует источники и определяет отсутствующие острова; `generate.py` создаёт детали; затем `nest_single.py KEY`, `export_svg.py KEY`, `build_assembly.py -- KEY --no-render`, `build_world.py`, `verify.py`, `verify_blends.py`. KEY: `01-Islands`, `02-Greenland`, `03-Australia`. Для репозитория вне `/workspace/-66-` установить `MAP_REPO`.

Источники и условия: пользовательский векторный атлас, NOAA ETOPO10 (условия в `data/source/ETOPO10-LICENSE.txt`), Natural Earth admin1 (public domain), Open Sans Light (лицензия в `Шрифт`). SHA256 использованных утверждённых Blender-файлов сохранены в `data/source-assemblies.json`.
