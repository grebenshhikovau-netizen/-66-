# Евразия — рельефные и плоские политические модули

Европа, Центральная Азия, Китай, Индия, Ближний Восток, Аравия и Юго-Восточная Азия собраны в общей системе координат. Россия показана в рельефной сцене как справочная готовая сборка из прежнего проекта. Исходные файлы России и Африки сохранены без изменений.

**120 политических модулей, 88 страновых групп.** В рельефном варианте 824 новые деревянные детали; в сплошном политическом — 226, в политическом со сквозной водой — 244. Справочные 67 деталей России в число новых деталей не входят. Китай сохраняет 33 отдельных модуля провинций и специальных территорий с единым покрытием страны.

## Что открыть

- **Евразия-рельеф-по-регионам.blend** — шесть уровней, разделённых на политические модули.
- **Евразия-политическая.blend** — сплошные плоские политические части без природных ступеней.
- **Евразия-политическая-с-водой.blend** — дополнительный плоский вариант с теми же сквозными речными и озёрными вырезами, что и рельеф. Удобен для смешанной карты с подсветкой.

Масштаб, положение X/Y, имена регионов и центры политических модулей совпадают во всех трёх файлах. Китай разделён на провинции; островные части остаются отдельной геометрией внутри соответствующего модуля. Никаких перемычек между разными островами нет.

## Как комбинировать в Blender

В коллекции `01_Политические_модули` есть страны `COUNTRY_…`, внутри — части `REG_…` и контейнеры `ЧАСТЬ_…`. Для перемещения всей страны используйте контейнер `СТРАНА_…`; для одной провинции — `ЧАСТЬ_…`.

Чтобы заменить рельефный регион плоским или обратно:

1. Держите оба основных `.blend` рядом в одной папке.
2. Выделите любую деревянную деталь нужной части или её контейнер.
3. В Text Editor откройте включённый текст `ЗАМЕНИТЬ_ВЫБРАННУЮ_ЧАСТЬ.py` и нажмите Run Script.

Скрипт заменяет только этот регион и сохраняет его текущее перемещение и поворот. Остальные регионы остаются на месте. Для выбора плоского варианта с водой впишите его имя в `SOURCE_NAME` в начале скрипта. Можно также использовать обычный Append коллекции `REG_…` из другого файла.

## Нижняя плоскость и надписи

У каждой деревянной детали начало отсчёта находится на её собственной нижней плоскости, локальное Z=0. Толщина листа по умолчанию 3 мм, суммарные отметки 3 / 6 / 9 / 12 / 15 / 18 мм. Изменяйте **Dimensions Z / Scale Z в Object Mode**, чтобы деталь росла от низа. Верхние ступени связаны драйверами с поддерживающими нижними деталями и следуют изменению их толщины.

Страновые надписи — заполненные замкнутые векторные кривые, без зависимости от установленного шрифта. Они привязаны к реальным деталям, следуют их повороту и масштабированию и остаются над верхней гранью. Очень малые страны оставлены без нечитаемой мелкой подписи; названия доступны в именах объектов. Надписи городов из сырого CDR в новую гравировку не включены.

Для ручной правки вершин в Edit Mode зависимости высот автоматически не пересчитываются: драйверы рассчитаны на изменение толщины через масштаб Z.

## Окраска

Пять покрытий: натуральная фанера `#e9dfca`, тик `#be7745`, орех `#77513b`, тёмный акцент `#44352e`, терракота `#ad6049`. У страны одно покрытие, одинаковое на всех ступенях, провинциях и островах. Соседние страны различаются; удалённые страны повторяют палитру. Материал каждой страны общий для её деталей. При обмене модулем сохраняется материал страны из открытой сцены.

`Страны-и-покрытия.csv` содержит назначение покрытий. `Маски-покрытия/` — цельные векторные маски стран. Цвета в файлах — ориентиры композиции: внешний вид морилки зависит от фанеры и числа проходов.

## Векторы и резка

- `SVG-по-регионам/<регион>/Слой-XX.svg` — замкнутые контуры каждой политической части на каждом реально присутствующем уровне.
- `Политические-SVG/` — сплошные плоские части.
- `Политические-SVG-с-водой/` — плоские части с водными отверстиями.
- `Общий-рельеф-слой-XX.svg` — общие природные массивы до политической нарезки.
- `Слой-XX-по-политическим-регионам.svg` — цветная сборочная схема.
- `Резка-без-дублей/` — вспомогательные общие линии резки с объединёнными совпадающими границами. В этом наборе линии могут быть открытыми: это общая трасса резки, редактируемые замкнутые мастера лежат отдельно по регионам.
- `Реки-и-озёра-сквозные.svg` — водная схема.
- `Гравировка-уровень-XX.svg` — редкие линии дюн и неглубокие кратеры.
- `Подписи-стран-в-кривых.svg` — надписи для гравировки.

Все SVG сохраняют общий видовой прямоугольник 1600 × 1000 мм для совмещения с существующей картой мира. Это не габарит одного континента. При открытии в CorelDRAW сохраняйте размер страницы и координаты. Не выполняйте автоматическое «вписать каждый файл в страницу».

Реки и озёра проходят насквозь через все деревянные уровни до оргстекла. Сухие аравийские вади имеют деревянное дно; кратеры вулканов — углубления гравировкой 0,35 мм, а не отдельные хрупкие кольца. Для них нужны две операции: резка наружного контура и гравировка кармана.

Общий прямоугольный лист оргстекла в Blender — справочная визуализация, **не контур производственной подложки**. Раскладку на листе, компенсацию пропила и окончательную проверку узких мест выполняют после выбора фактического масштаба и материала. Пороги укрупнения и минимальных площадей заданы в `data/config.json`.

Микрогосударства и несколько малых береговых частей сохранены отдельными редактируемыми объектами. Детали меньше 1 мм² перечислены в `Малые-политические-детали.json`: в текущем масштабе их разумно обозначать гравировкой либо оставлять только в цифровой сборке. Малые верхние обрезки рельефа опущены на нижние ступени; точечные касания контуров раскрыты микровырезами около 0,015 мм, чтобы получить замкнутые объёмные тела.

## Рельеф и обобщения

Высотная основа — ETOPO10/ETOPO1. Из неё строится единое сглаженное поле с разными художественными диапазонами для низких европейских гор, высоких азиатских хребтов и широкого Тибетского плато. Соседние возвышенности объединены до политической нарезки; случайные мелкие обрезки верхних ступеней опущены на нижний уровень. Поэтому естественный хребет продолжается через государственную границу, хотя фанерные модули можно заменять отдельно.

Выделены Альпы с Монбланом и Маттерхорном, Пиренеи, Карпаты, Скандинавия и три фьорда, Тянь-Шань, Памир, Тибет, Гималаи с Эверестом, Куньлунь и Каракорум, Загрос, Эльбурс, Аравийские нагорья, Декан и Гаты. Фудзи, Везувий, Этна и избранные вулканы Индонезии получают собственные ступенчатые конусы и карманы кратеров. Кракатау отмечен в справочнике, но не превращён в отдельную микродеталь, непригодную для текущего масштаба.

Главные реки и озёра укрупнены по ширине ради чтения и подсветки. Северный и Южный Арал разделены, единое историческое озеро не подставлялось. Мелкие притоки, озёра и случайные островки исключены. Сухие пустыни не заполнены вымышленной постоянной речной сетью.

Четыре разнесённые группы пользовательского CDR совмещены с существующей географической проекцией России. Замкнутые однозначные исходные фрагменты использованы при сборке; отсутствующие страны, острова и разделители восстановлены по Natural Earth. Исходный вектор для сравнения сохранён в `data/Исходник-CDR-справочно.svg`. Результат — декоративная географическая модель, не геодезический чертёж.

`Природные-объекты.csv` и `Схема-природных-объектов.svg` позволяют проверить расположение акцентов. `Детали-для-сборки.csv` связывает каждую физическую деталь с именем в Blender, страной и слоем.

## Повторная генерация

Основной архив `Евразия-комплект.zip` содержит готовые сцены, векторы, маски и превью. Для изменения алгоритма скачайте дополнительно [Евразия-генератор.zip](Евразия-генератор.zip) и распакуйте оба архива в одну папку. Генератор и геоданные для открытия готовых сцен не нужны.


Python с зависимостями из `requirements.txt`; проверено в Python 3.12 и Blender 4.3.2. Noto Sans Regular с лицензией приложен в `data/`. Для открытия готовых сцен Python-зависимости не нужны. Все необходимые геоданные уже заморожены в `data/`.

Для точного восстановления приложенной сборки используйте сохранённый `geometry.json`: начните с `export_mesh.py`, затем `make_labels.py`. Для нового построения высотного поля из DEM сначала выполните `generate.py` и `repartition.py`. У Python, встроенного в Blender, должна быть своя совместимая установка Shapely; её каталог можно передать через `PYTHONPATH`. В этой облачной среде Blender использует Python 3.13, поэтому двоичные пакеты от основного Python 3.12 ему не подходят.

```bash
python tools/generate.py
python tools/repartition.py
python tools/export_mesh.py
python tools/make_labels.py
python tools/finish_assets.py
blender -b -t 4 --python-exit-code 1 --python tools/build_scene.py -- --variant relief
blender -b -t 4 --python-exit-code 1 --python tools/build_scene.py -- --variant political
blender -b -t 4 --python-exit-code 1 --python tools/build_scene.py -- --variant political_water
```

Результаты геометрических и фактических Blender-проверок сохранены в `Проверка-*.json`. Исходная геометрия готовой России включена в новую сцену точной копией ранее проверенных 67 тел; новые Россия и Африка не генерировались.
